## 这是什么

Running 是一个面向**全球线上跑步赛事**的运动工具：把虚拟马拉松、城市线上跑、月度挑战赛这类「必须出门才能完成」的活动，搬回室内。

打开它，你不用换鞋、不用看天气、不用挤通勤，在客厅里也能刷完一场赛事任务，把里程、成绩和坚持天数留在自己的记录里。

适合这几类人：

- 想开始跑步，但总被加班、天气和通勤打断；
- 报名了线上赛事，却总凑不齐当月里程；
- 需要一点游戏化和打卡压力，才能把运动坚持下去。

## 核心特性

| 模块 | 能力 |
|---|---|
| 🏠 **室内跑模式** | 跑步机、原地跑、室内步行均可计入里程，不依赖场地与天气 |
| 🌍 **虚拟赛道** | 内置波士顿、柏林、东京、伦敦、纽约等经典赛道，跑量推进赛道进度 |
| 🎯 **赛事任务** | 订阅线上跑活动，按距离目标自动拆成每日小任务，跑完即打卡 |
| 📊 **数据看板** | 里程、配速、连续打卡天数、个人纪录一屏可见 |
| 🏅 **成绩卡** | 完赛自动生成可分享的成绩卡，记录每一次「在家跑完的世界」 |
| 🔄 **多端同步** | 手机、平板、网页端数据互通，随时接着上次的进度跑 |

## 为什么不是又一个计步器

普通计步器只负责「记录你已经跑了多少」，Running 负责「让你今天真的跑起来」。

- **有终点**：赛道有明确的下一站，而不是一个永远涨不完的数字；
- **有节奏**：长距离赛事被拆成每天 3～5 公里，门槛低到你愿意开始；
- **有反馈**：完赛成绩卡、连续打卡、赛段排名，让坚持被看见。

## 参与贡献

欢迎 Issue、PR 和想法。流程很简单：

1. Fork 本仓库并新建分支：`git checkout -b feat/your-idea`；
2. 提交改动：`git commit -m "feat: 你的改动"`；
3. 推送并发起 Pull Request；
4. 描述清楚「解决了什么问题」和「怎么验证」。

发现 bug 或想要新赛事赛道，直接开 Issue 就好。
